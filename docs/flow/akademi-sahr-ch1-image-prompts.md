# Image Prompts — «آکادمی سحر — فصل ۱: ورود»

**Genre:** Anime / light fantasy, magical school
**Palette:** Magic purple, night blue, warm gold, emerald green
**Mood:** Wondrous, mysterious, beautiful, slightly dark

## Spec
- **Format:** WebP (preferred) or JPG/PNG
- **Aspect ratio:** 16:9 (landscape)
- **Resolution:** ≥ 1280×720
- **File size:** ≤ 300 KB (compress with [squoosh.app](https://squoosh.app) if needed)
- **Keep center clear** — text overlays the middle of the image
- **No text, no watermarks, no logos** in the image

## After adding files
```bash
npm run scenes   # regenerate manifest
npm run dev      # images auto-appear
```

Global style suffix (append to every prompt below):
> `anime style illustration, Studio Ghibli inspired, magical fantasy school, soft lighting, detailed background art, beautiful color palette, no text, 16:9`
